Documentation & Guidance

Learn how deepDR-Canvas predicts drug sensitivity vectors from cancer patient mutation structures.

1. Input Genomic Data Formats

The predictor accepts mutations reported at the gene level (using HGNC Gene Symbols). When uploading a Mutation Annotation Format (MAF) file or CSV, the file must include standard headers matching standard genomics nomenclature.

Sample Mutation Data Template (MAF/CSV format): 
Hugo_Symbol  Entrez_Gene_Id  Variant_Classification  Variant_Type  SANGER_MODEL_ID
EGFR         1956            Missence_Mutation       SNP           SIDM00848
KRAS         3845            Missence_Mutation       SNP           SIDM00848
TP53         7157            Nonsense_Mutation       SNP           SIDM00848

2. DeepDR Model Transfer Design

DeepDR employs a multi-input deep neural network structure:

Genomic Alterations Encoder Translates mutation counts and gene panels (like CCLE CCLE_mutations.csv) into low-dimensional latent space representations using autoencoders.
Pharmacological Predictor Uses dense multilayer feedforward networks to map latent vector profiles to the IC50 values of 265 anti-cancer compounds.
